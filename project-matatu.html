Matatu Management System

Live Demo GitHub Repo

Project Overview

A comprehensive fleet management system designed specifically for matatu (public transport) owners in Kenya. This system helps manage daily operations from vehicle tracking to financial management.

Role: Lead Full-Stack Developer

Timeline: 4 months

Target Users: Matatu owners, fleet managers, drivers, and conductors

Technologies Used

PHP MySQL JavaScript HTML5 CSS3 Bootstrap jQuery Chart.js

Key Features

  • Vehicle Management: Track fleet details, maintenance schedules, and insurance
  • Booking System: Manage passenger bookings and seat allocation
  • Staff Management: Driver and conductor profiles, schedules, and payroll
  • Fuel Tracking: Monitor fuel consumption, purchases, and efficiency
  • Financial Management: Daily revenue tracking, expenses, and profit reports
  • Route Management: Optimize routes and schedule management
  • Reporting Dashboard: Real-time analytics and visual reports

Challenges & Solutions

Challenge 1: Real-time Data Sync

Managing real-time updates across multiple vehicles and users was complex.

Solution: Implemented AJAX polling and optimized database queries for near real-time updates.

Challenge 2: Complex Financial Calculations

Accurate daily profit calculations considering multiple variables (fuel, salaries, maintenance).

Solution: Built a comprehensive financial engine with automated calculations and audit trails.

Results & Impact

  • Successfully deployed for 5+ matatu SACCOs
  • Reduced manual paperwork by 80%
  • Improved fuel efficiency tracking saving 15% on fuel costs
  • Real-time financial visibility for owners

Future Improvements

  • Mobile app for drivers and conductors
  • GPS tracking integration
  • Automated SMS notifications
  • Payment gateway integration (M-Pesa)
