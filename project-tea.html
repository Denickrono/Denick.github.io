Tea Management System

Live Demo GitHub Repo

Project Overview

A modern web application built to help tea farmers automate their inventory, track collections, manage finances, and process applications digitally.

Role: Full-Stack Developer

Timeline: 3 months

Tech Stack: MERN (MongoDB/MySQL, Express, React, Node.js)

Technologies Used

Node.js React.js Tailwind CSS SQL Express.js JWT Auth RESTful API

Key Features

  • Farmer Profiles: Digital profiles for each farmer with historical data
  • Inventory Automation: Track tea leaf collections and green leaf delivery
  • Financial Management: Payment processing, bonuses, and deductions
  • Loan Applications: Digital application and approval system
  • Collection Records: Daily/weekly collection tracking by weight and quality
  • Reporting Dashboard: Analytics for production trends and payments
  • SMS Integration: Automated notifications for farmers

Challenges & Solutions

Challenge 1: Offline Access for Rural Areas

Many farmers have limited internet connectivity.

Solution: Implemented progressive web app (PWA) features and offline data sync.

Challenge 2: Complex Payment Calculations

Calculating payments based on weight, quality grades, and bonuses.

Solution: Built a flexible rule engine for payment calculations that admins can configure.

Results & Impact

  • Onboarded 500+ farmers in pilot phase
  • Reduced payment processing time from 2 weeks to 3 days
  • Improved inventory accuracy by 95%
  • Farmers can now track their earnings in real-time

Future Improvements

  • Weather integration for farming advice
  • Mobile app for farmers (React Native)
  • AI-based yield prediction
  • Integration with agricultural extension services
